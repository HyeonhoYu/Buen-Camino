Buen Camino 소리 녹음

사이트에서 들리는 스페인어 소리를 하나씩 녹음해요. 목록은 구간과 과 순서로 나오고, 아직 녹음하지 않은 첫 말에서 시작해요. 녹음은 이 브라우저에 저장되니 여러 번에 나눠서 해도 되고, 일부만 올려도 돼요. 녹음이 없는 말은 기기 음성으로 대신 나와요.

  • 사람 목소리로 녹음해도 되고 AI 목소리로 채워도 돼요. AI로 저장한 말도 나중에 녹음하면 사람 목소리로 바뀌어요.
  • 앞뒤 빈 소리와 음량은 도구가 자동으로 맞춰요. 처음부터 끝까지 한 목소리, 같은 속도로 맞추는 것이 좋아요.
  • 1구간의 소리 카드(a, ma, ca co cu 같은 것)는 글자 이름이 아니라 소리예요. AI에게도 그렇게 전해요.
  • 단축키: 스페이스 녹음 시작과 끝, P 다시 듣기, → 다음, ← 이전, A AI 목소리 만들기, S AI 목소리 저장

AI 목소리 설정

API 키 받는 법 (한 번만)
  1. aistudio.google.com에 Google 계정으로 로그인해요.
  2. Get API key를 누르고 Create API key로 키를 만들어요. 달토끼 녹음실에서 쓰던 키를 그대로 써도 돼요.
  3. 많이 만들 때는 무료 한도에 금방 걸릴 수 있어요. 그럴 때는 같은 화면에서 결제(유료 등급)를 켜면 돼요. 한도에 걸리면 도구가 잠깐 기다렸다가 다시 시도해요.
  4. 키를 위 칸에 붙여 넣고 저장해요. 키는 이 브라우저에만 남고, 코드나 저장소, 내려받는 zip에는 들어가지 않아요.
녹음 AI 이미 사이트에 올라간 것

남은 말 AI로 한꺼번에 채우기

지금 고른 목소리와 모델로, 아직 녹음도 AI도 없는 말을 차례로 만들어 저장해요. 분당 한도에 맞춰 천천히 진행하고, 하루 한도에 걸리면 멈춰요. 중간에 멈춰도 만든 것은 남아요.

사이트에 올리기

zip을 내려받아 저장소 맨 위(index.html이 있는 곳)에 풀면 assets/audio/ 폴더에 소리 파일과 manifest.js가 들어가요. 이미 사이트에 올라간 소리 목록도 manifest에 함께 들어가니, 이번에 만든 것만 있어도 괜찮아요. 올린 뒤 몇 분 지나 새로고침하면 사이트에서 녹음한 소리가 나와요.
